Questions, answered

Is it really free?

Yes — the default engines (Google Translate's public web endpoint and MyMemory) need no API key, no signup and no billing. It costs nothing to use.

Do I need an API key?

No. An API key is optional: if the free engines ever stop responding or hit a rate limit, you can add a free Gemini API key from Google AI Studio in ⚙️ settings and translation continues through Gemini. The key stays in your browser only.

Which translation API does it use?

Google Translate (the same web endpoint that powers Google's own translator), with MyMemory as an automatic fallback and Gemini as an optional third engine.

Why does audio sound wrong in some languages?

Browsers can only speak languages that have a voice installed on the device. LingoFlow therefore uses a local voice when one exists, and automatically switches to an online voice (via the bundled server.py) for every other language — so all 43 languages can be heard. Start the app with python server.py to enable that.

Does it work on phones?

Yes — the layout adapts to small screens, and copy, text-to-speech and language swapping all work on mobile browsers.
